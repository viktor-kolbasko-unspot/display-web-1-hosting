# Предварительные сборки UnSpot Display

Адрес предпросмотра — <https://viktor-kolbasko-unspot.github.io/display-web-1-hosting/>.

GitHub Pages публикует каталог `docs/` из ветки `main`. Здесь опубликован дисплей на React. Он поддерживает подключение по PIN, дневное расписание привязанной переговорной, недельное табло нескольких комнат, карточки встреч, QR и разрешённые администратором действия с бронями. Содержимое этого репозитория и сайта общедоступно.

## Как опубликовать сборку

1. В рабочем репозитории приложения собрать Vite SPA с базовым путём `/display-web-1-hosting/`. Для стандартного скрипта Vite команда — `npm run build -- --base=/display-web-1-hosting/`.
2. Синхронизировать содержимое готового `dist/` с каталогом `docs/` актуальной копии этого репозитория. Удалить устаревшие файлы предыдущей сборки и сохранить пустой `docs/.nojekyll`. Проверить, что `docs/index.html` существует, пути ресурсов содержат базовый путь, а публикуемые файлы предназначены для открытого доступа.
3. Закоммитить изменения в `docs/` и отправить в `main`. В сообщении коммита указать ревизию приложения. Состояние публикации видно в [Actions](https://github.com/viktor-kolbasko-unspot/display-web-1-hosting/actions).
4. После успешного развёртывания открыть сайт, проверить загрузку ресурсов и обновление вкладки на вложенном маршруте. У GitHub Pages нет серверного перенаправления всех путей на `index.html`. Для предпросмотра SPA можно использовать маршруты после `#`. Если сборка использует обычные URL, ей потребуется собственная обработка прямого входа на маршрут.

Чтобы восстановить предыдущую сборку, отменить её замену отдельным коммитом в `main`.

## Параметры GitHub Pages

В [Settings → Pages](https://github.com/viktor-kolbasko-unspot/display-web-1-hosting/settings/pages) источник — **Deploy from a branch**, ветка — **main**, каталог — **/docs**.
